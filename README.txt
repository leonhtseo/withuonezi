WITHU 휴대폰 설치 안내

1. 이 폴더의 파일들을 모두 HTTPS 웹 호스팅에 업로드합니다. (예: GitHub Pages, Netlify)
2. 안드로이드: Chrome에서 해당 주소 접속 → 메뉴 → 홈 화면에 추가/앱 설치.
3. 아이폰: Safari에서 해당 주소 접속 → 공유 → 홈 화면에 추가.
4. 앱에서 설정(톱니바퀴)에 Gemini API 키를 입력합니다. 키는 새로 열 때마다 다시 입력해야 합니다.

주의: ZIP이나 index.html을 휴대폰에서 직접 여는 것만으로 PWA 설치는 되지 않습니다. HTTPS 호스팅이 필요합니다.
채팅 기록은 기기의 브라우저 저장소에만 보관됩니다. 기기 변경 시 동기화되지 않으며, 브라우저 데이터 삭제 시 사라질 수 있습니다.
AI 답장은 인터넷 연결과 유효한 Gemini API 키가 필요합니다. 브라우저에서 직접 API를 호출하므로 개인용 테스트 용도로만 사용하세요. 공개 배포 시 서버를 통한 API 호출과 인증/사용량 제한이 필요합니다.
